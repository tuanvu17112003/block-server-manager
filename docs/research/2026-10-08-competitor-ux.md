## Synthesized 8 tabs (desktop, persistent header: status dot grey/green/amber/red + Start/Stop/Restart + players + version + address:port)
1. **Overview:** status + uptime, players chip, CPU/RAM bars, version/loader, Start/Stop/Restart/Kill, Open Folder, Copy IP, 3-line log tail, alert banner (crashed/EULA/port). Empty: Create CTA.
2. **Create wizard:** Type cards Vanilla/CF/MR → Search (search + source tabs + MC/loader filter + sort, cards logo/downloads/MC) → Configure (pack version + changelog, name unique, MC+loader read-only resolved, RAM slider + recommended + free-RAM warn, port auto+conflict, EULA checkbox required, Java Auto text) → Install progress + log + Cancel + Retry → Create & Start. Vanilla shortcut: MC version + name/RAM/port/EULA.
3. **Console:** auto-scroll colored log + search/filter + Clear/Export, cmd input history + Send, Stop/Kill-confirm/Restart, quick chips (save-all, say, time, weather), RCON/process attached state.
4. **Players:** table avatar/name/UUID/online/OP/white/ban/last-seen/playtime + Search + Filter Online/OP/White/Ban + Refresh + row Kick-reason/Ban/Unban/OP/Whitelist/Gamemode/Teleport/Heal (confirm, needs running) + Add player offline via usercache. Disabled when stopped.
5. **Worlds:** current card (name/size/last/seed) + library grid Local+Shared search Upload.zip/Download/Delete-confirm/Duplicate + Activate (needs stopped + auto-backup prompt) + New empty (seed + level-type). Warn replaces level-name.
6. **Backups:** table name/created/size/type/note + Backup Now (name + shutdown-during checkbox) + Auto toggle + interval + Max kept + Excludes hint + row Restore-confirm (in-place vs reset + overwrite warn)/Download/Delete-confirm + progress + retention notice.
7. **Metrics:** live CPU%/RAM% vs limit/Players/Uptime/TPS+MSPT (or — needs RCON hint) + graphs CPU/RAM 1h-72h range + Shift-zoom + Players history + Disk + alert opt-in deferred. Empty when stopped.
8. **Settings minimal:** name, MOTD, max-players, difficulty/gamemode (restart badge), port, RAM slider, online-mode toggle (cracked loses OP warn), Save dirty + Restart banner, Show advanced files link (properties/eula read-only hint). No separate Versions/Java/Plugins tabs MVP.

Deferred: Files full browser, Schedules/cron, Users/roles, DBs, Network/allocs, Activity — keep slot extensible. Worlds covers 80% Files need.

## Create-flow (Vanilla 2 clicks, modpack ~4)
+New → Type (Vanilla|CF|MR) → (modpack) search/filter cards → detail pack version + changelog → Configure name/pack-version/MC+loader read-only/RAM+recommend/port auto/EULA/Java Auto → Install & Create (Downloading x%, Installing loader, Stripping client mods + log + Cancel) → auto pre-first-run backup → land Console Start pulsing + EULA re-confirm + LAN/port hint + client parity notice.

## Scope note (unchecked Content+settings)
- Versions MANDATORY as picker not tab (MC + pack-version + locked loader; else break + client mismatch).
- Java MANDATORY backend not tab (auto 8/17/21 per MC; read-only line).
- Properties PARTIALLY (7 fields: port/max-players/difficulty/gamemode/MOTD/online-mode/view-distance + restart badge; defer raw edit).
- Plugins/mods browser DEFERRABLE (pack resolves deps; manual mods/ later).
- EULA + RAM hidden mandatories (block Start until EULA; slider 4G vs 12G ATM10).

## Risks
CF API key/ToS, server-vs-client pack strip (mrpack-install), Java provisioning (Temurin bundle vs download, ARM paths), EULA persist, ports/firewall/LAN UPnP vs Docker, world format Java vs Bedrock level.dat, backup growth prune (keep 7 / 4GB), metrics source RCON vs log vs Docker (Vanilla no TPS), offline NBT parse (MVP usercache+lists only), creep (Files/Scheduler/roles defer).
